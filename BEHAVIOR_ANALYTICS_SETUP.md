# ⏱️ User Behavior Time Tracking - Документація

## Огляд

Система відстеження часової поведінки користувачів збирає метрики для розуміння швидкості прийняття рішень клієнтами.

---

## 📊 Метрики, що збираються

### 1. **Час на роздуми** (`time_to_cart_add`)
- **Що відстежує**: Час від відкриття сторінки товару до кліку "Додати в кошик"
- **Тригер старту**: `performance.now()` при завантаженні `product.html`
- **Тригер завершення**: Виклик `addToCartHandler()`
- **Діапазон**: 1с - 30хв (значення поза діапазоном ігноруються)

### 2. **Шлях до каси** (`time_cart_to_checkout`)
- **Що відстежує**: Час від першого додавання товару до переходу на checkout
- **Тригер старту**: Перший виклик `addToCart()` (зберігається в `localStorage.cart_started_at`)
- **Тригер завершення**: Виклик `window.checkout()`
- **Діапазон**: 1с - 2год (значення поза діапазоном ігноруються)

### 3. **Швидкість оформлення** (`time_checkout_completion`)
- **Що відстежує**: Час заповнення форми замовлення
- **Тригер старту**: Перехід на `checkout.html` (зберігається в `localStorage.checkout_load_time`)
- **Тригер завершення**: Успішна відправка замовлення (`submitOrder()`)
- **Діапазон**: 5с - 30хв (значення поза діапазоном ігноруються)

## 🗄️ Структура даних у Firestore

**Колекція**: `analytics_timings`

**Документ**:
```json
{
  "type": "time_to_cart_add" | "time_cart_to_checkout" | "time_checkout_completion",
  "durationSeconds": 45.3,
  "timestamp": Timestamp,
  "device": "mobile" | "desktop",
  
  // Додаткові поля залежно від типу:
  "productId": "abc123",           // тільки для time_to_cart_add
  "productName": "Латяо Classic",  // тільки для time_to_cart_add
  "cartItemsCount": 3,             // для cart_to_checkout та checkout_completion
  "cartTotal": 450,                // для cart_to_checkout та checkout_completion
  "deliveryMethod": "nova",        // тільки для checkout_completion
  "paymentMethod": "online"        // тільки для checkout_completion
}
```

## 🖥️ Адмін-панель

### Розташування
Секція **"⏱️ Поведінка Клієнтів"** в табі **Статистика** (`admin.html`)

### Відображення
- 3 картки з середніми значеннями
- Форматування часу: `45с`, `2хв 15с`, `1год 05хв`
- При наведенні показується точне середнє значення в секундах

### Функції
- `loadBehaviorAnalytics()` - завантажує дані з Firestore
- `formatDuration(seconds)` - форматує секунди в читабельний рядок
- `updateBehaviorUI()` - оновлює DOM-елементи

## 📁 Файли, що були змінені

| Файл | Зміни |
|------|-------|
| `product.html` | Додано `trackTimeToCart()`, імпортовано `addDoc`, `serverTimestamp` |
| `js/layout.js` | Додано логіку в `addToCart()` та `checkout()` |
| `checkout.html` | Додано трекінг в `submitOrder()` |
| `admin.html` | Нова секція HTML + функції `loadBehaviorAnalytics()`, `formatDuration()` |

---

## 🔧 localStorage ключі

| Ключ | Призначення |
|------|-------------|
| `cart_started_at` | Timestamp першого додавання в кошик |
| `checkout_load_time` | Timestamp переходу на checkout |

Обидва ключі автоматично видаляються після трекінгу.

---

## 📈 Інтерпретація даних

| Метрика | Короткий час | Довгий час |
|---------|--------------|------------|
| Час на роздуми | Швидке рішення, імпульсивна покупка | Клієнт вагається, потребує більше інформації |
| Шлях до каси | Впевненість у покупці | Можливі сумніви, порівняння цін |
| Швидкість оформлення | Проста форма, зручний UX | Складна форма, технічні проблеми |

## 🚀 Як протестувати

1. Відкрийте сторінку товару
2. Почекайте кілька секунд
3. Натисніть "Додати в кошик"
4. Перейдіть на checkout
5. Заповніть форму та оформіть замовлення
6. Перевірте консоль на наявність повідомлень `⏱️`
7. В адмін-панелі перейдіть на вкладку "Статистика"
8. Перевірте секцію "Поведінка Клієнтів"

---

## ⚠️ Примітки

- Трекінг **не блокує** основний флоу (fire-and-forget)
- Помилки трекінгу логуються, але не впливають на UX
- Дані зберігаються безстроково (можна додати автоочищення)
- Для фільтрації за датою потрібно додати окрему логіку
