# 🧪 Тестування Модуля Подарунків - Refined Gift Logic

## 📋 Огляд змін

**Проблема:** Якщо продукт є подарунком (price: 0, qty: 1) і користувач хоче купити той самий продукт за гроші, стандартна логіка `addToCart` збільшувала кількість безкоштовного подарунка.

**Рішення:** Подарунок і платний варіант одного продукту тепер є **окремими позиціями** в кошику.

---

## 🔑 Ключові зміни

### 1. Унікальна ідентифікація за `id` + `isGift`

**Було:**
```javascript
const existingItem = window.cart.find(item => item.id === product.id);
```

**Стало:**
```javascript
const productIsGift = product.isGift === true;
const existingItem = window.cart.find(item => 
  item.id === product.id && 
  (item.isGift === true) === productIsGift
);
```

### 2. Картка рендериться за індексом масиву

**Було:** `data-id="${item.id}"`
**Стало:** `data-cart-index="${cartIndex}"`

Це дозволяє мати два елементи з однаковим `id`, але різним `isGift`.

### 3. Нові функції для роботи з індексом

- `window.updateQtyByIndex(cartIndex, delta)` - замість `updateQty(productId, delta)`
- `window.removeItemByIndex(cartIndex)` - замість `removeItem(productId)`

Старі функції залишені для зворотної сумісності (LEGACY).

## ⚙️ Технічні деталі

### Як працює пошук існуючого товару:

```javascript
// СТАРИЙ спосіб (НЕ ПРАЦЮЄ для подарунків):
const existingItem = cart.find(item => item.id === product.id);
// Проблема: знайде БУДЬ-ЯКИЙ товар з таким id (подарунок або платний)

// НОВИЙ спосіб (ПРАВИЛЬНО):
const productIsGift = product.isGift === true;
const existingItem = cart.find(item => 
  item.id === product.id &&
  (item.isGift === true) === productIsGift
);
// Знайде ТІЛЬКИ товар з таким id ТА таким же статусом подарунка
```

### Чому `(item.isGift === true) === productIsGift`?

Це гарантує строгу перевірку boolean:
- Подарунок: `(true === true) === true` → ✅ true
- Платний: `(false === true) === false` → ✅ true
- Undefined: `(undefined === true) === false` → ✅ true (коректно)

## 🚨 Усунення проблем

### Проблема: Два подарунки замість одного

**Причина:** `fetchAndInjectGifts()` викликається двічі або не перевіряє `existingGift`.

**Рішення:**
```javascript
// В fetchAndInjectGifts()
const existingGift = window.cart.find(item => 
  item.id === product.id && item.isGift === true
);

if (!existingGift) {
  window.cart.push({ ...product, isGift: true });
}
```

### Проблема: Не можу купити платний варіант

**Причина:** Продукт додається з `isGift: true` замість `false`.

**Рішення:** Перевірте що кнопка "Купити" в каталозі НЕ встановлює `isGift: true`:
```javascript
window.addToCart({
  id: product.id,
  name: product.name,
  price: product.price,  // NOT 0!
  // isGift: false (або взагалі не вказувати)
});
```

### Проблема: Платний варіант відображається як подарунок

**Причина:** `item.isGift` має truthy значення (наприклад, string "false").

**Рішення:** Завжди використовуйте строгу перевірку:
```javascript
const isGift = item.isGift === true;  // NOT: if (item.isGift)
```
