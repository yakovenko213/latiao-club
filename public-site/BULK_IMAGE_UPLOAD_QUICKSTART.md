# 📸 Bulk Image Upload - Quick Start

## За 3 хвилини

### Крок 1: Підготуйте зображення
Назвіть файли як SKU товарів:
```
9840.jpg    → SKU "9840"
1520.png    → SKU "1520"
8765.webp   → SKU "8765"
```

### Крок 2: Відкрийте Admin Panel
1. Перейдіть до розділу **"Товари"**
2. Натисніть **"📸 Bulk Image Upload"** (синя кнопка)

### Крок 3: Завантажте файли
1. У модальному вікні натисніть **"Choose Files"**
2. Виберіть усі зображення (Ctrl+A для вибору всіх)
3. Натисніть **"🚀 Почати завантаження"**

### Крок 4: Перегляньте результати
Логи покажуть:
- ✅ Успішно оновлено
- ❌ SKU не знайдено (перевірте назву файлу)

---

## Важливо! ⚠️

### SKU має бути STRING у Firestore:
```javascript
// ✅ Правильно:
{ sku: "9840" }

// ❌ Неправильно:
{ sku: 9840 }  // Це число, не спрацює!
```

### Підтримувані формати:
`.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.bmp`, `.svg`

### Обмеження:
- Максимум **5 файлів одночасно** обробляються
- Назва файлу = SKU товару (без розширення)
- Файл `9840.jpg` → шукає товар з `sku: "9840"`

---

## Типові помилки

### "Товар не знайдено для SKU"
**Рішення:**
1. Перевірте назву файлу (без пробілів, спецсимволів)
2. Відкрийте Firestore → `products` → знайдіть товар
3. Переконайтеся, що поле `sku` є STRING:
   ```
   sku: "9840"  ← Має бути в лапках!
   ```

### "Firebase: Missing permissions"
**Рішення:**
1. Увійдіть в адмін-панель
2. Перевірте `localStorage.isAdmin = "true"`
