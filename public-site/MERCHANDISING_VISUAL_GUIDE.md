## Крок 4: Drag & Drop

### Наведіть курсор на картку

```
┌──────────────┐
│         ①    │
│   ┌──────┐   │  ← З'являється Drag Handle
│   │  ≡   │   │
│   │ Drag │   │
│   └──────┘   │
│   [Фото 1]   │
│              │
│ Latiao Orig. │
│   150 грн    │
└──────────────┘
      ↑
   Hover тут
```

### Перетягніть картку

**Початкова позиція:**
```
① Latiao Original → ② Latiao Spicy → ③ Latiao Sweet
```

**Зажміть ЛКМ і тягніть:**
```
① Latiao Original
          ↓ (drag)
          ↓
② Latiao Spicy → ③ Latiao Sweet → [ порожнє місце ]
```

**Відпустіть кнопку:**
```
① Latiao Spicy → ② Latiao Original → ③ Latiao Sweet
   (нова поз.)      (перемістився)
```

**Номери автоматично оновляться!**

## Крок 5: Візуальний feedback

### При перетягуванні:

```
┌──────────────────┐  ┌──────────────┐  ┌──────────────┐
│ ① Latiao Spicy   │  │              │  │ ③ Latiao Swe │
│  (normal)        │  │   [Ghost]    │  │  (normal)    │
└──────────────────┘  └──────────────┘  └──────────────┘
                           ↑
                    ┌──────────────┐
                    │ ② Lat. Orig. │  ← Ви тримаєте це
                    │  (floating)  │     (тінь, rotation)
                    └──────────────┘
```

**Стилі:**
- **Обрана картка** (chosen): масштаб 1.05, помаранчева обводка, велика тінь
- **Ghost (місце)**: прозорість 30%, сірий градієнт
- **Drag (летить)**: прозорість 90%, поворот 3°, велика тінь

## Крок 6: Збережіть порядок

**Після зміни кнопка активується:**

```
┌────────────────────────────────────────────────────────┐
│  Товари в категорії        [12 товарів]               │
│                                                         │
│  ┌─────────────────────────────────────────────────┐  │
│  │  💾 Зберегти порядок                            │  │  ← Зелена
│  └─────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

**Клікніть на кнопку:**

```
┌─────────────────────────────────────────────────────┐
│  ⏳ Збереження...                                    │  ← Loading
└─────────────────────────────────────────────────────┘
```

**Після збереження:**

```
┌─────────────────────────────────────────────────────┐
│  ✅ Збережено!                                       │  ← Успіх (2 сек)
└─────────────────────────────────────────────────────┘

Toast повідомлення:
┌─────────────────────────────────────┐
│ ✅ Порядок збережено для 12 товарів! │
└─────────────────────────────────────┘
```

**Кнопка знову стає неактивною:**

```
┌─────────────────────────────────────────────────────┐
│  💾 Зберегти порядок                (disabled)      │
└─────────────────────────────────────────────────────┘
```

## 🧠 Автоматичні стратегії

### Приклад: "Margin Booster" (дорогі першими)

**До:**
```
① Latiao Original (150 грн)
② Latiao Spicy (165 грн)
③ Latiao Sweet (140 грн)
④ Latiao Hot (180 грн)
```

**Клік на 💰 Margin Booster:**

```
┌──────────────────┐
│ 💰 Margin Booster │  ← Клік
└──────────────────┘
```

**Після:**
```
① Latiao Hot (180 грн)      ← Найдорожчий
② Latiao Spicy (165 грн)
③ Latiao Original (150 грн)
④ Latiao Sweet (140 грн)    ← Найдешевший
```

**Не забудьте зберегти!**

## 🐛 Troubleshooting — Візуальна діагностика

### Проблема: Товари не завантажуються

**Що побачите:**
```
┌──────────────────────────────────────┐
│                                       │
│      📦                               │
│   Немає товарів у цій категорії      │
│                                       │
│   📋 Категорія: Помірно гостре латяо │
│   Slug: pom-rno-gostre-latyao        │
│                                       │
│  ┌──────────────┐  ┌──────────────┐ │
│  │ 🔍 Debug DB  │  │ 📦 Всі товари│ │
│  └──────────────┘  └──────────────┘ │
└──────────────────────────────────────┘
```

**Дія:**
1. Клікніть "🔍 Debug Database"
2. Відкрийте консоль (F12)
3. Подивіться таблицю з товарами

### Проблема: Drag не працює

**Перевірте:**
```
Console (F12):
> merchSortableInstance
→ Sortable { ... }  ✅ ОК

> merchSortableInstance
→ null  ❌ НЕ ініціалізовано
```

**Рішення:** Перезавантажте сторінку

## 🎓 Поради експерта

### 💡 Порада #1: Комбінуйте стратегії
```
1. Спочатку: 🔥 Hot Deals (знижки першими)
2. Потім: Вручну перетягніть топ-3 популярні товари вгору
3. Збережіть: 💾 Зберегти порядок
```

### 💡 Порада #2: Сезонність
```
Весна/Літо: ✨ New Drops (новинки)
Осінь: 📦 Inventory Flush (розпродаж залишків)
Зима: 💰 Margin Booster (дорогі товари)
```

### 💡 Порада #3: A/B тестування
```
Тиждень 1: Стратегія А (дорогі першими)
Тиждень 2: Стратегія Б (новинки першими)
Аналіз: Яка стратегія дала більше продажів?
```
