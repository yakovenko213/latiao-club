## Альтернативні назви колонок (також підтримуються):

### Англійською:
- Title / Product Name → `name`
- SKU / Code / Article → `sku`
- Price / Cost → `price`
- Spiciness / Spicy Level / Level → `spiciness`
- Description / Desc → `description`
- Weight / Characteristics → `weight`
- Ingredients / Composition → `ingredients`
- Category / Type → `category`

### Shopify формат:
- Title → `name`
- Variant SKU → `sku`
- Variant Price → `price`
- Body (HTML) → `description`
- Type → `category`
- Tags → `tags` (автоматично парсить гостроту)
- Image Src → `image`
- Variant Inventory Qty → `stock`

## Примітки:

1. **Обов'язкова колонка:** Тільки "Назва товару" (або Title)
2. **Гострота:** Від 0 до 5. Якщо більше 5 - буде обмежена до 5
3. **Ціна:** Може містити символи валюти (89,99 грн, $12.50, 45.5) - система автоматично очистить
4. **Зображення:** Якщо є URL - додайте колонку "Фото" або "Image URL"
5. **Залишок:** Якщо є - додайте колонку "Залишок" або "Stock" (число)

## Швидкий спосіб створити файл:

### Excel / Google Sheets:
1. Створіть новий файл
2. Скопіюйте таблицю вище
3. Вставте у лист 1
4. Збережіть як `.xlsx`

### CSV:
```csv
Назва товару,Артикул,Вартість,Рівень гостроти,Опис,Характеристика,Склад,Категорія
Лапша гостра Сичуаньська,LAT-001,89.99,4,Традиційна китайська лапша з Сичуаню,120г,Пшеничне борошно,Локшина
Снеки з перцем Халапеньо,SNK-002,45.50,3,Хрусткі кукурудзяні снеки,85г,Кукурудза,Снеки
```

Збережіть як `products.csv` з кодуванням UTF-8.
