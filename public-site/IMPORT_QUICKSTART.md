# ⚡ Швидкий старт: Імпорт товарів

## 🎯 Два способи імпорту:

### 1️⃣ **Shopify CSV** (зелена кнопка) - якщо є експорт з Shopify
- Один клік
- Автоматичне розпізнавання всіх полів
- Фільтрує дублікати та варіанти

### 2️⃣ **Імпорт Excel** (фіолетова кнопка) - для власних файлів ⭐ ПОКРАЩЕНО!
- Підтримує `.xlsx`, `.xls`, `.csv`
- **Візуальний мапінг колонок** з dropdown-меню
- **Селектор категорій** - призначте одну категорію для всіх товарів
- **Налаштування залишку** за замовчуванням
- Попередній перегляд перших 5 рядків
- **Валідація в реальному часі**

---

## 📋 Мінімальна структура файлу

**Обов'язкова тільки 1 колонка:** `Назва товару` або `Title`

**Рекомендовані колонки:**
```
Назва товару | Артикул | Вартість | Категорія | Опис
```

**Повний набір (підтримка українських назв):**
```
Назва товару | Артикул | Вартість | Рівень гостроти | Опис | Характеристика | Склад | Категорія
```

---

## ⚡ Швидкі кроки:

1. **Відкрийте:** https://my-magazin-81c96.web.app/admin.html
2. **Увійдіть** в адмін-панель
3. **Перейдіть** у розділ "Товари"
4. **Натисніть** "📂 Імпорт Excel" (фіолетова кнопка)
5. **Перетягніть** ваш `.xlsx` файл
6. **🆕 Оберіть категорію** для всіх товарів (або залиште "Автоматично")
7. **🆕 Встановіть залишок** за замовчуванням (якщо у файлі немає колонки Stock)
8. **Перевірте зіставлення колонок** - система автоматично розпізнає їх
9. **Змініть мапінг** у випадаючих списках, якщо потрібно
10. **Натисніть** "✅ Імпортувати товари" (кнопка активна тільки після валідації)
11. **Почекайте** ~5-10 секунд
12. ✅ **Готово!**

## 🆕 Нові можливості візуального мапінгу:

### 📂 Селектор категорій:
```
• "Не призначати категорію" - залишити як є у файлі
• "🤖 Автоматично (з колонки Category)" - взяти з Excel
• Або оберіть конкретну категорію - застосується до ВСІХ товарів
```

### 📦 Залишок за замовчуванням:
```
• Вкажіть значення (наприклад, 100)
• Використовується для товарів БЕЗ колонки Stock
• Якщо у файлі є колонка Stock - вона має пріоритет
```

### 🔗 Візуальне зіставлення:
- **Dropdown над кожною колонкою** з повним списком полів
- **Автоматичне розпізнавання** українських та англійських назв
- **Попередній перегляд** перших 5 рядків для перевірки
- **Валідація в реальному часі** - кнопка Import активна тільки коли все правильно

### ⚠️ Інтелектуальна валідація:
- Показує помилку, якщо не обрано поле "Назва товару"
- Блокує імпорт до виправлення помилок
- Підказки з поясненням проблеми

## 🔧 Автоматичні перетворення:

| Що вводите | Що отримуєте |
|------------|--------------|
| `89,99 грн` | `89.99` (number) |
| `$12.50` | `12.5` (number) |
| `Гострота: 4` | `spiciness: 4` |
| `<p>Опис</p>` | `Опис` (очищений HTML) |
| _(порожньо Stock)_ | `залишок за замовчуванням` |
| _(порожньо Category)_ | `обрана категорія або з колонки` |

## 🐛 Поширені проблеми:

**"Файл порожній"** → Перевірте, що є хоча б 1 рядок з даними (окрім заголовка)

**"Товари не відображаються"** → Оновіть сторінку (Ctrl+Shift+R)

**"Помилка читання"** → Збережіть файл у форматі `.xlsx` (не `.xls`)

**"Кнопка Import неактивна"** → Оберіть колонку для поля "Назва товару"
