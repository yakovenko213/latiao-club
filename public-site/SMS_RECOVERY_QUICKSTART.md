# 🚀 SMS Recovery - Quick Start

## ⚡ Швидке налаштування (5 хвилин)

### Крок 1: TurboSMS API Token
1. Відкрийте Admin Panel
2. Натисніть ⚙️ Settings
3. Вставте **TurboSMS API Token**
4. Натисніть "Зберегти"

### Крок 2: Увімкніть SMS розсилку
1. В тому ж вікні Settings
2. Знайдіть секцію **"SMS налаштування (Покинуті кошики)"**
3. Увімкніть перемикач ✅
4. (Опціонально) Змініть шаблон повідомлення
5. Натисніть "Зберегти"

### Крок 3: Оновіть домен
⚠️ **ОБОВ'ЯЗКОВО** - Замініть тестовий домен на свій!

**Файл:** `admin.html` (рядок ~2008)

**Знайдіть:**
```javascript
const recoveryLink = `https://latiao-snack.web.app/checkout.html?recovery_id=${phone}`;
```

**Замініть на:**
```javascript
const recoveryLink = `https://ВАШ-ДОМЕН.com/checkout.html?recovery_id=${phone}`;
```

### Крок 4: Готово! 🎉

Тепер можете:
1. Відкрити **"Покинуті кошики"**
2. Натиснути **"📩 SMS"** біля будь-якого кошика
3. Клієнт отримає SMS з посиланням для відновлення

---

## 📋 Checklist перед запуском

- [ ] TurboSMS API Token додано в Settings

- [ ] Баланс TurboSMS поповнено
