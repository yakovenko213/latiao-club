# 🎁 Модуль Подарунків - Інструкція

## Огляд

Модуль **"Подарунки та сеймплінг"** дозволяє адміністратору обирати продукти, які автоматично додаються до кошика клієнта як безкоштовні подарунки.

---

## 📋 Функціонал

### Адміністративна панель (admin.html)

1. **Меню "🎁 Подарунки"** - нова секція в бічній панелі адміністратора
2. **Вибір продуктів** - список усіх активних продуктів з чекбоксами
3. **Попередній перегляд** - показує обрані подарунки перед збереженням
4. **Збереження** - зберігає список активних подарунків у Firestore

### Клієнтська частина (js/layout.js)

1. **Автоматичне завантаження** - при завантаженні будь-якої сторінки
2. **Ін'єкція в кошик** - подарунки додаються з ціною 0 грн
3. **Спеціальна візуалізація**:
   - 🎁 Бейдж "Подарунок"
   - Зелене підсвічування
   - Напис "Подарунок від Latiao Snack"
   - Відображення "0 грн" або "Безкоштовно"
4. **Захист від змін**:
   - Не можна змінити кількість
   - Можна тільки видалити

---

## 🗄️ Структура даних Firebase

### Колекція: `settings`
### Документ: `global_gifts`

```javascript
{
  activeGiftIds: ["productId1", "productId2", "productId3"],
  updatedAt: Timestamp,
  updatedBy: "admin@example.com"
}
```

### Властивості продукту-подарунка в кошику:

```javascript
{
  id: "productId",
  name: "Назва продукту",
  price: 0,  // Завжди 0 для подарунків!
  image: "https://...",
  stock: 999,
  spiciness: 2,
  quantity: 1,  // Завжди 1
  isGift: true  // 🔑 Головна ознака подарунка
}
```

## 🚀 Як користуватися

### Для адміністратора:

1. Увійдіть в [admin.html](admin.html)
2. Натисніть на **"🎁 Подарунки"** в лівому меню
3. Поставте галочки біля продуктів, які хочете зробити подарунками
4. Перегляньте список обраних подарунків у блоці "Активні подарунки"
5. Натисніть **"💾 Зберегти зміни"**

### Для клієнта:

Подарунки з'являються **автоматично** при:
- Завантаженні будь-якої сторінки магазину
- Відкритті кошика
- Переході на сторінку оформлення замовлення

## 🛡️ Правила та обмеження

### ✅ Дозволено:
- Видалити подарунок з кошика (кнопка X)
- Мати декілька різних подарунків одночасно

### ❌ Заборонено:
- Змінювати кількість подарунка (завжди = 1)
- Додавати той самий подарунок вручну (буде дублікат з ціною 0)

---

## 📊 Обчислення суми замовлення

Подарунки **НЕ впливають** на загальну суму замовлення:

```javascript
// Функція calculateTotal() в layout.js
function calculateTotal() {
  return window.cart.reduce((sum, item) => 
    sum + (item.price * (item.quantity || item.qty || 1)), 0
  );
}
// Оскільки item.price = 0 для подарунків, вони не додаються!
```

## 🧪 Тестування

### Сценарій 1: Додавання подарунків
1. Адмін: виберіть 2-3 продукти як подарунки → Збережіть
2. Клієнт: відкрийте будь-яку сторінку магазину
3. Клієнт: відкрийте кошик
4. **Очікуваний результат**: всі обрані подарунки в кошику з ціною 0 грн

### Сценарій 2: Редагування кількості
1. Клієнт: спробуйте натиснути +/- біля звичайного продукту → працює
2. Клієнт: спробуйте натиснути на "Безкоштовно" біля подарунка → нічого не відбувається
3. **Очікуваний результат**: кількість подарунка залишається = 1

### Сценарій 3: Оформлення замовлення
1. Клієнт: додайте звичайні продукти + подарунки в кошику
2. Клієнт: перейдіть на checkout.html
3. Клієнт: перегляньте підсумок замовлення
4. **Очікуваний результат**: 
   - Подарунки відображаються зеленим
   - Сума замовлення не включає подарунки
   - При збереженні замовлення `isGift: true` зберігається

## 🔄 Синхронізація

### Коли подарунки оновлюються:
- При кожному завантаженні сторінки (`loadLayout()` → `fetchAndInjectGifts()`)
- При рефреші сторінки
- При переході між сторінками

### Коли подарунки НЕ дублюються:
```javascript
// Перевірка в fetchAndInjectGifts()
const existingGift = window.cart.find(item => 
  item.id === product.id && item.isGift === true
);
if (!existingGift) {
  // Тільки тоді додаємо
}
```

## ❗ Важливі примітки

1. **Firestore правила**: переконайтеся що адміністратори мають право на запис в `settings/global_gifts`
2. **Кеш**: подарунки завантажуються при кожному `loadLayout()`, тому зміни застосовуються одразу
3. **localStorage**: подарунки зберігаються в `latiao_cart` разом зі звичайними продуктами
4. **Замовлення**: при збереженні замовлення поле `isGift: true` передається в Firestore

## 🆘 Усунення проблем

### Проблема: Подарунки не з'являються
**Рішення:**
1. Перевірте консоль браузера на помилки
2. Переконайтеся що в Firestore є документ `settings/global_gifts`
3. Перевірте що `activeGiftIds` містить валідні ID продуктів
4. Перевірте що продукти існують в колекції `products`

### Проблема: Подарунки дублюються
**Рішення:**
1. Очистіть localStorage: `localStorage.removeItem('latiao_cart')`
2. Перезавантажте сторінку
3. Перевірте логіку `existingGift` в `fetchAndInjectGifts()`

### Проблема: Можна змінити кількість подарунка
**Рішення:**
1. Перевірте що `item.isGift === true` в кошику
2. Перевірте функції `updateQty()`, `increaseQty()`, `decreaseQty()`
3. Очистіть кеш браузера
