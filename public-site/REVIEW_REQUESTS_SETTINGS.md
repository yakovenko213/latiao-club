# 📋 Налаштування запитів на відгук

## 🎯 Огляд функціональності

Система управління запитами на відгук дозволяє:
- 📝 Створювати та редагувати шаблони повідомлень
- 🤖 Автоматично надсилати запити після виконання замовлення
- ⏰ Встановлювати затримку відправки
- 🔄 Використовувати динамічні теги для персоналізації

---

## 🚀 Як користуватися

### 1. Відкрити налаштування
1. Перейдіть в **Адмін-панель** → Розділ **Відгуки**
2. Натисніть таб **"Запити на відгук"**
3. Натисніть кнопку **"⚙️ Налаштування"** у верхньому правому куті

---

## 🤖 Автоматична відправка

### Як увімкнути
1. У модальному вікні перемкніть **"Автоматична відправка"** → **ON**
2. Встановіть затримку:
   - **Дні:** кількість днів після виконання (наприклад, `1`)
   - **Години:** додаткові години (наприклад, `0`)
3. Натисніть **"Зберегти налаштування"**

### Приклад
```
Затримка: 1 день, 0 годин
Замовлення виконано: 2 лютого 2026, 14:00
Запит буде надіслано: 3 лютого 2026, 14:00
```

### ⚠️ Важливо
- Система перевіряє замовлення **кожну годину**
- Відправка відбувається **автоматично** для замовлень зі статусом "Виконано"
- Запит надсилається **один раз** на замовлення

---

## 📝 Шаблони повідомлень

### Створення нового шаблону
1. Натисніть **"+ Додати шаблон"**
2. Введіть **назву шаблону**
3. Напишіть текст повідомлення
4. Використовуйте **динамічні теги** (див. нижче)
5. Натисніть **"Зберегти налаштування"**

### Динамічні теги

| Тег | Що замінює | Приклад |
|-----|------------|---------|
| `{customer_name}` | Ім'я клієнта | Олександр |
| `{order_id}` | Номер замовлення | #5678 |
| `{product_list}` | Список товарів | • (арт:1234) Latiao Classic ×2<br>• (арт:5678) Latiao Spicy ×1 |

### Приклад шаблону

```
Вітаємо, {customer_name}! 👋

Дякуємо за покупку в Latiao! 🌶️

Ваше замовлення #{order_id}:
{product_list}

Нам дуже важлива ваша думка! Як вам наші гострі снеки?

🎁 Залиште відгук і отримайте знижку 10% на наступне замовлення!

З повагою, команда Latiao 🌶️
```

### Встановити шаблон за замовчуванням
1. Натисніть іконку **⭐ (зірочка)** біля шаблону
2. Шаблон буде позначено як **"За замовчуванням"**
3. Цей шаблон використовуватиметься для всіх запитів

### Видалити шаблон
1. Натисніть іконку **🗑️ (кошик)** біля шаблону
2. Підтвердіть видалення
3. ⚠️ **Стандартний шаблон видалити не можна**

## 🔧 Технічні деталі

### Структура Firestore
```javascript
settings/review_config {
  autoSend: boolean,          // Чи увімкнено автоматичну відправку
  delayDays: number,          // Затримка в днях
  delayHours: number,         // Затримка в годинах
  templates: [                // Масив шаблонів
    {
      id: string,             // Унікальний ID
      name: string,           // Назва шаблону
      content: string,        // Текст з тегами
      isDefault: boolean      // Чи є основним
    }
  ],
  updatedAt: timestamp        // Час останнього оновлення
}
```

### Дані замовлення (tracking)
Після відправки запиту в `orders/{orderId}` зберігається:
```javascript
{
  reviewRequestSentAt: timestamp,     // Час першої відправки
  reviewRequestResendCount: number,   // Кількість повторних відправок
  reviewRequestLastSentAt: timestamp, // Час останньої відправки
  reviewRequestTemplateId: string,    // ID використаного шаблону
  autoSent: boolean                   // Чи відправлено автоматично
}
```

## 📊 Робочий процес

### Ручна відправка
1. Адмін змінює статус замовлення на **"✔️ Виконано"**
2. Замовлення з'являється в таблиці **"Виконані замовлення"**
3. Адмін натискає **"Запит відгуку"**
4. Система:
   - Використовує **шаблон за замовчуванням**
   - Замінює **динамічні теги** реальними даними
   - Відкриває **WhatsApp** з готовим повідомленням
   - Зберігає мітку `reviewRequestSentAt`

### Автоматична відправка
1. Адмін змінює статус замовлення на **"Виконано"**
2. Система фіксує час виконання `completedAt`
3. Через встановлену затримку (1 день + 0 годин):
   - Система перевіряє замовлення
   - Якщо `reviewRequestSentAt == null`
   - Автоматично надсилає запит
   - Зберігає мітку `autoSent: true`

## 🧪 Тестування

### Перевірити налаштування
1. Відкрийте **Консоль браузера** (F12)
2. Введіть: `reviewSettings`
3. Побачите поточні налаштування

### Перевірити автоматичну відправку
1. Увімкніть автоматичну відправку

3. Змініть статус тестового замовлення на "Виконано"
4. Через 5 секунд перевірте консоль: `Auto-sending review request...`

## 📖 FAQ

### Чому запит не надсилається автоматично?
- Перевірте, чи увімкнено **"Автоматична відправка"**
- Перевірте, чи минула встановлена **затримка**
- Перевірте, чи є **номер телефону** у замовлення
- Переконайтеся, що є **шаблон за замовчуванням**

### Як змінити посилання на сторінку відгуку?
У коді функції `sendReviewRequest` змініть рядок:
```javascript
const reviewLink = `https://latiao-store.web.app/review.html?orderId=${orderId}`
```

### Чи можна надсилати через Telegram/Viber?
Так, змініть:
```javascript
window.open(`https://wa.me/${phone}?text=...`)  // WhatsApp
// на
window.open(`https://t.me/share/url?url=...`)   // Telegram
```
