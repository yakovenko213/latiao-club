# 🌟 Персоналізована система відгуків

## 📋 Що змінилося?

Тепер кожен клієнт отримує **унікальне посилання** для залишення відгуку з автоматичним завантаженням його даних!

---

## 🔗 Як працює новий URL

### Старий спосіб (загальний):
```
https://latiao-snack.com.ua/review
```
❌ Клієнт має вводити своє ім'я вручну
❌ Немає зв'язку з конкретним замовленням

### Новий спосіб (персоналізований):
```
https://latiao-snack.com.ua/review?orderId=abc123xyz
```
✅ Ім'я клієнта підтягується автоматично
✅ Відгук прив'язується до замовлення
✅ Зручність для клієнта = більше відгуків

---

## 📝 Як використовувати в SMS шаблонах

### Доступні плейсхолдери:
- `{customer_name}` → "Олена" (перше ім'я клієнта)
- `{order_id}` → "#12345" (короткий номер замовлення)
- `{product_list}` → список товарів з артикулами
- `{review_link}` → **НОВИЙ!** персональне посилання для відгуку

### Приклад SMS шаблону:
```
Привіт, {customer_name}! 👋

Дякуємо за замовлення {order_id}!

Залиште відгук за 30 секунд:
{review_link}

Ваша думка важлива для нас! ⭐⭐⭐⭐⭐
```

### Що отримає клієнт:
```
Привіт, Олена! 👋

Дякуємо за замовлення #12345!

Залиште відгук за 30 секунд:
https://latiao-snack.com.ua/review?orderId=abc123xyz

Ваша думка важлива для нас! ⭐⭐⭐⭐⭐
```

## 🎯 Переваги для бізнесу

1. **Підвищена конверсія**: Клієнту не потрібно вводити дані = більше відгуків
2. **Аналітика**: Можна відстежувати, з якого замовлення прийшов відгук
3. **Автоматизація**: Ім'я клієнта підставляється автоматично
4. **Безпека**: Посилання унікальні, важко підробити

## ⚙️ Налаштування в Admin Panel

1. Відкрийте розділ **"Налаштування відгуків"**
2. Створіть або редагуйте SMS шаблон
3. Використовуйте `{review_link}` замість статичного посилання
4. Збережіть зміни
5. Тестуйте на реальному замовленні!

---

## 🧪 Як протестувати

### Крок 1: Отримайте orderId
У розділі **"Запити на відгуки"** знайдіть замовлення зі статусом "Виконано"

### Крок 2: Створіть тестове посилання
```
https://latiao-snack.com.ua/review?orderId=PASTE_ORDER_ID_HERE
```

### Крок 3: Відкрийте посилання
- ✅ Має відкритися форма відгуку
- ✅ Поле "Ваше ім'я" має бути автоматично заповнене
- ✅ В консолі браузера має з'явитися: `✅ Order loaded: ORDER_ID | Customer: ІМ'Я`

### Крок 4: Надішліть тестовий відгук
- Оберіть зірки (1-5)
- Напишіть текст (мінімум 20 символів)
- За бажанням додайте фото
- Натисніть "Надіслати відгук"

### Крок 5: Перевірте в Firestore
Відкрийте колекцію `reviews` і знайдіть новий документ:
```json
{
  "customerName": "Олена Петренко",
  "rating": 5,
  "text": "Дуже смачно!",
  "status": "pending",
  "orderId": "abc123xyz",
  "createdAt": "...",
  "photoUrl": "..." // якщо додали фото
}
```

## 🔧 Технічні деталі

### Автоматичне завантаження даних
При відкритті посилання з `orderId`:
1. JavaScript витягує `orderId` з URL (`URLSearchParams`)
2. Робиться запит до Firestore: `getDoc(doc(db, 'orders', orderId))`
3. Якщо замовлення знайдене, ім'я клієнта автоматично підставляється
4. В консолі виводиться лог: `✅ Order loaded: ...`

### Збереження відгуку
Всі відгуки зберігаються з `status: "pending"`:
```javascript
const reviewData = {
  customerName: "...",
  rating: 5,
  text: "...",
  status: "pending",  // Завжди pending для модерації
  orderId: "...",     // Прив'язка до замовлення
  createdAt: serverTimestamp()
}
```

## ❓ FAQ

**Q: Чи працює старе посилання без orderId?**  
A: Так! Якщо клієнт відкриє звичайне посилання `https://latiao-snack.com.ua/review`, він просто введе ім'я вручну.

**Q: Що якщо orderId неправильний?**  
A: Форма все одно працює, але ім'я не підставиться автоматично. В консолі з'явиться: `⚠️ Order not found`

**Q: Чи можна відредагувати ім'я?**  
A: Так, клієнт може виправити ім'я перед відправкою.

**Q: Скільки символів займає посилання в SMS?**  
A: Приблизно 55-60 символів. Враховуйте при складанні шаблону!
