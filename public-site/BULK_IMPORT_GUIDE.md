# 📊 Посібник з масового імпорту товарів

## ✅ Функціональність вже реалізована!

Ваша система має **дві** потужні опції імпорту:

### 🟢 **Опція 1: Швидкий Shopify CSV імпорт** (зелена кнопка)
- **Кнопка:** "Shopify CSV"
- **Призначення:** Одним кліком імпортувати CSV експорт з Shopify
- **Формат:** Автоматично розпізнає стандартні колонки Shopify:
  - `Title` → `name`
  - `Variant Price` → `price`
  - `Variant SKU` → `sku`
  - `Body (HTML)` → `description`
  - `Image Src` → `image`
  - `Variant Inventory Qty` → `stock`
  - `Type` → `category`
  - `Tags` → `tags` + `spiciness` (автопарсинг)
  - `Handle`, `Vendor`, `Status`

### 🟣 **Опція 2: Розширений Excel імпорт** (фіолетова кнопка)
- **Кнопка:** "Імпорт Excel"
- **Призначення:** Імпорт з власного Excel/CSV файлу з кастомним мапінгом
- **Підтримка:** `.xlsx`, `.xls`, `.csv`
- **Функції:**
  - Drag & Drop файлу
  - Візуальне зіставлення колонок
  - Попередній перегляд (5 рядків)
  - Прогрес-бар з лічильником

---

## 📋 Мапінг українських заголовків

Система **автоматично розпізнає** такі українські колонки:

| Українська назва колонки | Поле у Firestore | Тип даних |
|--------------------------|------------------|-----------|
| **Назва товару** / Товар | `name` | string |
| **Артикул** / Код | `sku` | string |
| **Ціна** / Вартість / Кост | `price` | number |
| **Рівень гостроти** / Гострота | `spiciness` | number (0-5) |
| **Опис** / Описання | `description` | string |
| **Характеристика** / Вага | `weight` або `characteristics` | string |
| **Склад** | `ingredients` | string |
| **Категорія** / Тип | `category` | string |
| **Фото** / Зображення / URL | `image` | string (URL) |
| **Залишок** / Кількість | `stock` | number |

## 🎯 Підтримувані формати

### ✅ **Формат 1: Ваш власний український Excel**

**Приклад структури файлу (`products.xlsx`):**

| Назва товару | Артикул | Вартість | Рівень гостроти | Опис | Характеристика | Склад | Категорія |
|--------------|---------|----------|-----------------|------|----------------|-------|-----------|
| Лапша гостра китайська | LAT-001 | 89.99 | 3 | Класична лапша з Сичуаню | 120г | Пшеничне борошно, олія | Локшина |
| Снеки з перцем чилі | SNK-002 | 45.50 | 5 | Супер гострі снеки | 85г | Кукурудза, чилі | Снеки |
| Соус гострий | SAU-003 | 120 | 4 | Традиційний соус | 250мл | Томати, чилі | Соуси |

**Що робити:**
1. Натисніть **"Імпорт Excel"** (фіолетова кнопка)
2. Перетягніть ваш `.xlsx` файл у зону завантаження
3. Система покаже таблицю зіставлення - **перевірте**, чи правильно зіставилися колонки
4. Якщо щось не так - змініть в випадаючому списку над кожною колонкою
5. Натисніть **"Імпортувати товари"** (зелена кнопка внизу)
6. Почекайте завершення (прогрес-бар покаже статус)
7. Готово! ✅

### ✅ **Формат 2: Shopify CSV Export**

**Що робити:**
1. Експортуйте товари з Shopify (Products → Export → CSV)
2. Натисніть **"Shopify CSV"** (зелена кнопка)
3. Виберіть `.csv` файл
4. Система автоматично розпізнає формат і завантажить товари

**Обробка:**
- Дублікати фільтруються за `Handle`
- Рядки-варіанти (без `Title`) пропускаються автоматично
- Статус "archived" / "draft" ігнорується

## 🔄 Процес імпорту

### Крок 1: Завантаження файлу
- Підтримка `.xlsx`, `.xls`, `.csv`
- Drag & Drop або вибір файлу
- Бібліотека: [SheetJS](https://sheetjs.com/)

### Крок 2: Парсинг та зіставлення
- Автоматичне розпізнавання колонок (українська + англійська + Shopify)
- Візуальна таблиця з попереднім переглядом (5 рядків)
- Випадаючі списки для ручного коригування

### Крок 3: Валідація
- Обов'язкове поле: `name` (назва товару)
- `price`: автоматичне очищення від символів валюти
- `spiciness`: обмеження 0-5
- `image`: перевірка на валідний URL
- **Важливо:** Якщо рядок без назви - він пропускається

### Крок 4: Batch Upload
- Firestore `writeBatch` для оптимальної швидкості
- Ліміт: 500 товарів на batch (автоматично розбивається на партії)
- Прогрес-бар показує статус в реальному часі

### Крок 5: Звіт
```
✅ Успішно імпортовано: 71 товарів
⏭️ Пропущено (дублікати/варіанти): 12
❌ Помилок: 0
```

## 🐛 Troubleshooting

### Проблема: "Файл порожній або містить тільки заголовки"
**Рішення:** Переконайтесь, що файл має принаймні 2 рядки (заголовок + дані)

### Проблема: "Помилка читання файлу"
**Рішення:** 
- Перевірте формат файлу (`.xlsx`, `.xls`, `.csv`)
- Перевірте кодування (UTF-8)
- Відкрийте файл у Excel/Google Sheets і пересбережіть

### Проблема: Колонка не зіставляється автоматично
**Рішення:** Вручну оберіть правильне поле в випадаючому списку над колонкою

### Проблема: Товари не з'являються після імпорту
**Рішення:** 
- Оновіть сторінку (Ctrl + Shift + R)
- Перевірте консоль браузера (F12) на наявність помилок
- Перевірте Firestore Database у [Firebase Console](https://console.firebase.google.com/project/my-magazin-81c96/firestore)
