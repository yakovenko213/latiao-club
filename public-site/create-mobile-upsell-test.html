🎁 Тестове мобільне Upsell правило

📋 Що робить цей скрипт:

  • • Знаходить 2 перших видимих товари
  • • Створює правило: товар 1 → рекомендує товар 2
  • • Встановлює 10% знижку на комбо
  • • Активує для мобільної сторінки продукту

Після створення:

  1. Відкрийте сторінку товару #1 на мобільному
  2. Прокрутіть вниз до кнопки "Додати в кошик"
  3. Побачите мобільний bundle з комбо-пропозицією
  4. Натисніть "Додати обидва" для тесту
