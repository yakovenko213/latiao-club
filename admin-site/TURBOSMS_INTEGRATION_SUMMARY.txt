## Key Implementation Details

### 1. **Phone Number Validation**
- Auto-converts to +380 international format
- Handles formats: `0501234567`, `80501234567`, `380501234567`

### 2. **API Integration**
- Fetches `turbo_sms_api_key` and `alpha_name` from `settings/general`
- Fetches templates from `settings/review_automation`
- Sends POST to `https://api.turbosms.ua/message/send.json`

### 3. **Template Processing**
- Randomly selects one template from available options
- Replaces `{customer_name}` with first name
- Replaces `{review_link}` with `https://latiao-snack.com.ua/review?orderId=[id]`

### 4. **Success Handling**
- Shows toast: "Запит надіслано!"
- Updates order: `review_request_sent: true`
- Marks as "Надіслано" in UI

### 5. **Error Handling**
- Shows alert with error message from API
- Button returns to normal state
- Try/catch prevents admin panel crash

### 6. **Loading State**
- Button disabled during API call
- Shows spinner animation
- Prevents double-click

## Required Firestore Setup

### settings/general
```json
{
  "turbo_sms_api_key": "YOUR_API_KEY",
  "alpha_name": "LatiaoCafe"
}
```

### settings/review_automation
```json
{
  "templates": [
    {
      "id": "timestamp",
      "text": "Message with {customer_name} and {review_link}",
      "createdAt": "ISO date"
    }
  ]
}
```
