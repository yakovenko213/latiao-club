Налаштування TurboSMS

Інтеграція SMS розсилки для Restock Notifications

Крок 1: Введіть дані TurboSMS

Отримайте ці дані в особистому кабінеті TurboSMS: turbosms.ua/cabinet.html

📍 Знаходиться в розділі "API" → "HTTP API" у вашому кабінеті TurboSMS

💾 Буде збережено в поле: turboSmsToken

📍 Ваше зареєстроване ім'я відправника (максимум 11 символів). Має бути схвалено TurboSMS.

💾 Буде збережено в поле: senderName

Що відбувається після збереження?

  • ✅ Дані зберігаються в Firestore колекції config/turbosms_config
  • ✅ Поля: turboSmsToken та senderName
  • ✅ Адмін-панель автоматично використовуватиме ці дані для відправки SMS
  • ✅ Доступ до цих даних мають лише авторизовані адміністратори
  • ⚠️ Зберігайте API Key в таємниці! Не діліться з іншими.

🔒 Безпека

Поточна реалізація: API Key зберігається в Firestore і доступний адмінам. Це прийнятно для внутрішнього використання, але для підвищення безпеки рекомендується:

  • 🔹 Перенести відправку SMS в Firebase Cloud Functions
  • 🔹 Зберігати ключі в Firebase Config (firebase functions:config:set)
  • 🔹 Додати rate limiting для запобігання зловживань
