Test Real-time Sync

Verify instant updates without page refresh

Setup:

Open 2 Browser Windows:
  • Window 1: Admin CRM Board (https://admin-store-latio.web.app)
  • Window 2: Public Checkout (https://my-magazin-81c96.web.app)

Steps:

  1. 1. Window 1: Navigate to CRM tab and keep it visible
  2. 2. Window 2: Fill checkout form with new data
  3. 3. Window 2: Change phone to: +380997654321
  4. 4. Wait 2-3 seconds for auto-save
  5. 5. Window 1: Watch CRM board
✅ Expected Result:
  • • Window 1 updates automatically
  • • New card appears with phone +380997654321
  • • NO page refresh needed
  • • Time shows "щойно"
  • • Console shows: "🔄 Real-time update: Cart data changed"

Test Drag & Drop

Move card through sales pipeline

Steps:

  1. 1. In CRM board, find your test card in "Новий лід"
  2. 2. Drag the card to "Контакт встановлено" column
  3. 3. Check console (F12) for update logs
  4. 4. Refresh the page
✅ Expected Result:
  • • Card moves smoothly to new column
  • • Console shows: "✅ Статус картки оновлено"
  • • After refresh, card stays in new column
  • • Firestore document updated with new crm_status
  • • updated_at timestamp refreshed
